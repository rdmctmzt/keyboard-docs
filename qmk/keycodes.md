# 键值表

QMK / VIA 改键使用 **16-bit keycode**（线上 **大端** 两字节），不是厂商键盘的 `{ type, code1, code2 }`。

数值对齐驱动 `keyLabelUtils.CODE_TO_BYTE` / VIA v12（`keyboard-demo`）字典。

## 注意事项

| 条件 | 说明 |
|---|---|
| 配合改键 API | `setKey` / `getKeymap` 读写的就是该数值 |
| 穿透键 | `KC_TRNS` = `0x0001` |
| 高级键编码 | `LT` / `MT` / `MO` 等见下方「高级键编码范围」 |
| 宏绑定 | keymap 写 `MACRO(n)`，内容见 [宏](./api/macro) |
| 协议版本 | 宏 / 自定义基址在 v10/v11/v12 不同；下表默认 **v12** |

```js
await ServiceQmk.setKey(0, 2, 3, 0x0004) // KC_A
await ServiceQmk.setKey(0, 2, 4, 0x0001) // KC_TRNS
await ServiceQmk.setKey(0, 2, 5, 0x5101) // MO(1)
```

## 高级键编码范围

| 类别 | 范围 | 公式（摘要） |
|---|---|---|
| Mods + 基本键 | `0x0100`–`0x1FFF` | `modMask \| kc`，如 `S(kc)=0x0100\|kc` |
| Layer Tap `LT` | `0x4000`–`0x4FFF` | `0x4000 \| (layer << 8) \| kc` |
| `TO` | `0x5010`–`0x501F` | `0x5010 + n` |
| `MO` | `0x5100`–`0x511F` | `0x5100 + n` |
| `DF` | `0x5200`–`0x521F` | `0x5200 + n` |
| `TG` | `0x5300`–`0x531F` | `0x5300 + n` |
| `OSL` | `0x5400`–`0x541F` | `0x5400 + n` |
| `TT` | `0x5800`–`0x581F` | `0x5800 + n` |
| Layer Mod | `0x5900`–`0x59FF` | — |
| Mod Tap `MT` | `0x6000`–`0x7FFF`（注意与 MACRO 区间重叠，解析时 MACRO 优先） | — |
| `MACRO(n)` v12 | `0x7700`–`0x777F` | `0x7700 + n` |
| `CUSTOM(n)` v12 | `0x7E00`–`0x7EFF` | `0x7E00 + n` |

| 宏 / 自定义其它版本 | 基址 |
|---|---|
| MACRO v11 | `0x7702 + n` |
| CUSTOM v11 | `0x7F00 + n` |
| MACRO v10 | `0x5F12 + n` |
| CUSTOM v10 | `0x5F80 + n` |
