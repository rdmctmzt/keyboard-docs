# 键值表

可改写键 / 默认键在协议里都是 **3 字节**：

```
{ type, code1, code2 }
```

鼠标改键与键盘共用多数 `type` 定义；另外有**鼠标功能键表**（`0x50` 编号与键盘不同）和**火力键**（`0x70`）。

## 注意事项

| 条件 | 说明 |
|---|---|
| 配合改键 API | `setKey` / `getKeymap` 写入的就是这三字节 |
| 宏不是改 `list` 能播的 | 绑物理键要用 `type=0x60` / `0x61` |
| `0x50` 编号 | **不要套用键盘特殊功能表**；见下方鼠标功能键 |
| HID usage | 普通键 `code2` 是键盘 HID usage，不是 `KeyboardEvent.code` |

```js
await ServiceMouse.setKey(0, 4, { type: 0x40, code1: 0, code2: 2 }) // 右键
```

---

## type 一览

| type | 十进制 | 类别 | code1 / code2 含义 |
|---|---|---|---|
| `0x10` | 16 | 普通键盘键 | `code1`=修饰键位掩码；`code2`=HID Usage |
| `0x12` | 18 | 快捷键组合 | 同 `0x10` |
| `0x20` | 32 | 系统电源类 | `code1`=`0x81/0x82/0x83`；`code2` 常为 0 |
| `0x30` | 48 | 多媒体 / 消费控制 | `code1`=Usage；`code2`=页/附加 |
| `0x40` | 64 | 鼠标按键 | 见下方鼠标表 |
| `0x50` | 80 | 鼠标特殊功能 | `code1`=功能号（**鼠标表**）；`code2` 常为 0 |
| `0x60` | 96 | 宏 | `code1`=宏槽；`code2`=循环类型 |
| `0x61` | 97 | 宏（指定次数） | `code1`=宏槽；`code2`=次数 2–255 |
| `0x70` | 112 | 火力键 | `code1`=间隔单位；`code2`=次数 / 按住 |

---

## 0x10 / 0x12 普通键与组合键

### 修饰键掩码（code1）

| bit | 值 | 修饰键 |
|---|---|---|
| 0 | `0x01` | LCtrl |
| 1 | `0x02` | LShift |
| 2 | `0x04` | LAlt |
| 3 | `0x08` | LGUI / Win |
| 4 | `0x10` | RCtrl |
| 5 | `0x20` | RShift |
| 6 | `0x40` | RAlt |
| 7 | `0x80` | RGUI |

### 常用 HID Usage（code2）

| code2 | 键 | code2 | 键 |
|---|---|---|---|
| `0x04`–`0x1d` | A–Z | `0x1e`–`0x27` | 1–0 |
| `0x28` | Enter | `0x29` | Esc |
| `0x2a` | Backspace | `0x2b` | Tab |
| `0x2c` | Space | `0x3a`–`0x45` | F1–F12 |

```js
// Ctrl+C
{ type: 0x12, code1: 0x01, code2: 0x06 }
```

## 0x50 鼠标特殊功能键（code1）

`type=0x50`，`code2` 一般为 0。编号对齐固件 `Keyboard_Function_Type`（**与键盘表不同**）：

| code1 | 功能 | code |
|---|---|---|
| `0x01` | Fn0 | `KEY_MO0` |
| `0x02` | 按键灯开关 | `BL_TOG` |
| `0x03` / `0x04` | 灯光模式 + / − | `BL_MOD` / `BL_RMOD` |
| `0x05` / `0x06` | 灯光颜色 + / − | `BL_HUI` / `BL_HUD` |
| `0x07` / `0x08` | 灯光亮度 + / − | `BL_VAI` / `BL_VAD` |
| `0x09` / `0x0a` | 灯光速度 + / − | `BL_SPI` / `BL_SPD` |
| `0x0b` | 自定义灯光 1 | `BL_DEFINE1` |
| `0x0c` | 复位 | `KYE_RESET` |
| `0x0d`–`0x0f` | 蓝牙通道 1–3 | `MODE_BLE1`… |
| `0x10` | 2.4G 模式 | `MODE_2P4G` |
| `0x11` | USB 模式 | `MODE_USB` |
| `0x12` | 电量显示 | `BATT_STATUS` |
| `0x13` | 扫描延时 | `KYE_SCAK_DELAY_SET` |
| `0x14` | 参数切换（短按 CPI，长按 3 秒切回报率） | `KEY_CPI_SET` |
| `0x15` | 模式切换（短按切蓝牙通道，长按 3 秒配对） | `KEY_MODE_SET` |

```js
// 参数切换键
{ type: 0x50, code1: 0x14, code2: 0 }
```

## 0x60 / 0x61 宏键

| type | code1 | code2 |
|---|---|---|
| `0x60` | 宏槽 `0–15` | `0` 执行 1 次 / `1` 按住循环 / `3` 切换播放 |
| `0x61` | 宏槽 `0–15` | 重复次数 `2–255` |

详见 [宏](./api/macro)。

---

## 0x70 火力键

默认发射**左键**。

| 字段 | 含义 |
|---|---|---|
| `code1` | 间隔单位：`0` = 默认 2ms；其余为 `N × 2` ms（上限 255×2） |
| `code2` | `0` = 按住期间按间隔连发；`1–255` = 发射次数 |

```js
// 8ms 间隔，按住连发
{ type: 0x70, code1: 4, code2: 0 }

// 4ms 间隔，发射 5 次
{ type: 0x70, code1: 2, code2: 5 }
```
